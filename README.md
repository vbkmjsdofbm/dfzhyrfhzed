# 心动小测 · TA 是不是也在偷偷喜欢你

单页静态产品，零依赖、纯前端。

## 包内容

- `index.html` —— 唯一入口，已包含全部样式、交互、32 道题库与 10 个结果文案。

## 特性

- 无外部图片、无外部字体、无第三方 JS 库，全部内联，断网也能打开。
- 无后端、无接口、无数据库，不采集任何用户数据。
- 适配手机与电脑，答题时选完自动翻页，支持键盘 1–4 / A–D。

## 部署方式

1. **直接上传**：把 `index.html` 放进站点根目录或任意子目录即可，不需要构建、不需要安装依赖。
2. **zip 上传**：支持整包上传的静态托管（对象存储静态网站、云托管、网盘建站等）可直接上传本压缩包。
3. **本地预览**：双击 `index.html` 用浏览器打开即可完整运行。

## 注意

- 入口文件名必须是 `index.html`，改名后部分托管会找不到首页。
- 页面里没有绝对路径引用，放在子目录（例名 `xxx.com/heart/`）也能正常工作。
- 修改文案：题库在 `<script>` 内的 `Q` 数组（32 题），结果在 `RES` 对象（10 个），选项第二个值就是它对应的结果编号，改文案不必动逻辑。
- 发布前建议保留页脚那句“趣味测试仅供娱乐，别拿结果去质问他”。
